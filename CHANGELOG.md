# Changelog

## 0.1.0

- First release: ledger of structured, machine-checkable documentation claims. Registration requires the claim to hold against the pinned docs. Anyone can challenge with a docs hash. Grounded model extraction, exact-match consensus on the observed value, integer-only comparison, freshness window, cooldown, bounded history, event log.
- 35 unit tests and 26 direct tests (mocked web, model and clock).
